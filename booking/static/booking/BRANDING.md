# Transgate logo assets

The PNG files are the exact originals supplied by the user on 8 October 2026.
Do not redraw the wordmark or substitute a letter T for the company symbol.

- `transgate-logo.png`: original 1080 x 1080 wordmark image.
- `transgate-symbol.png`: original 1080 x 1080 standalone symbol image.
- `transgate-logo.svg`: wordmark display viewport, `102 497 876 86`.
- `transgate-symbol.svg`: symbol display viewport, `286 334 510 411`.

The SVG files embed the original PNG bytes and hide only the large empty outer
margins. They preserve the supplied shapes, colours and aspect ratio. Use the
wordmark in page headers, and the symbol in compact brand tiles and the favicon.
The handbook builder applies the same wordmark viewport to the original PNG.
Keep its viewport in sync if a replacement source has different dimensions.
