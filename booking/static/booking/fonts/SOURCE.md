# DM Sans

These unmodified variable TrueType files are self-hosted so the application does
not depend on an external font service on the company network.

Source: [Google Fonts, DM Sans](https://github.com/google/fonts/tree/5b35b7208dd4100571326fdf37f030b32a524232/ofl/dmsans)

Pinned upstream revision: `5b35b7208dd4100571326fdf37f030b32a524232`.

- `DMSans[opsz,wght].ttf` is stored as `dm-sans-variable.ttf`.
- `DMSans-Italic[opsz,wght].ttf` is stored as `dm-sans-italic-variable.ttf`.
- `OFL.txt` contains the upstream copyright and SIL Open Font License 1.1.

The font covers normal and italic styles with variable weights from 100 to 1000.
Email templates use the same font family with Arial/sans-serif fallbacks for mail
clients that cannot use DM Sans.
